# Portfolio (Vanilla HTML/CSS/JS)

This is a lightweight personal portfolio scaffold built with plain HTML, CSS, and JavaScript.

How to view

1. Open `index.html` in your browser (no build step required).
2. Toggle dark mode using the moon icon in the header.

Customization

- Edit content in `index.html`.
- Update colors and tokens in `css/style.css`.
- Add images to the `assets/` folder.

Design choices

- Cool Blues/Teals palette (user-selected)
- CSS variables for light/dark themes
- IntersectionObserver for reveal animations
